# 凛祢 V2 语音运行包

这个目录保存桌宠运行所需的语音启动脚本和参考音频，不包含训练集、私人对话或 API Key。

## 所需权重

将资源仓库中的两份 V2 权重放进 GPT-SoVITS：

```text
GPT_weights_v2/rinne_e15.ckpt
SoVITS_weights_v2/rinne_e8_s456.pth
```

根目录 README 会给出完整下载和安装步骤。

## 指定 GPT-SoVITS 目录

默认目录是项目根目录下：

```text
GPT-SoVITS-v2pro-20250604
```

如果解压软件额外生成了一层同名目录，启动脚本也会自动识别。

## 启动与停止

- `启动凛祢语音服务.bat`：启动稳定 V2 语音服务。
- `停止凛祢语音服务.bat`：只停止本运行包启动的进程。

运行状态、日志、临时配置和配置备份均在本目录生成，已被 Git 忽略。
