# 凛祢 V2 语音运行包

这里存放语音参考 WAV 和语音启动、停止脚本。

第一次安装，请按[主安装指南](../../README.md#voice)下载语音程序和权重、修改配置，再启动语音。

## 两份权重放在哪里

以下路径都以 GPT-SoVITS 的语音目录为起点，也就是能看到 `api_v2.py` 和 `runtime` 的文件夹。

| 文件 | 放置位置 |
| --- | --- |
| `rinne_e15.ckpt` | `GPT_weights_v2\rinne_e15.ckpt` |
| `rinne_e8_s456.pth` | `SoVITS_weights_v2\rinne_e8_s456.pth` |

放好后，还要按主指南修改 `GPT_SoVITS\configs\tts_infer.yaml`。

## 使用本目录的脚本

脚本默认从项目目录下的 `GPT-SoVITS-v2pro-20250604` 文件夹寻找语音程序，也能识别解压后多出的一层同名文件夹。

- 双击 `启动凛祢语音服务.bat`：启动 V2 语音。
- 双击 `停止凛祢语音服务.bat`：停止本运行包启动的语音进程。

如果语音程序放在其他位置，按[主指南中的命令](../../README.md#start)在实际语音目录启动即可。

不要同时用脚本和命令重复启动语音服务。脚本的日志、运行状态和临时配置保存在本目录。
