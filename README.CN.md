# Open-LLM-VTuber-Rinne

凛祢桌宠支持文字和语音对话、九套服装、日记与长期记忆。

完整的中文操作步骤在[主 README](README.md)。按自己的情况选择入口即可：

- [第一次安装](README.md#prepare)：准备软件、下载项目、填写密钥。
- [安装 V2 语音](README.md#voice)：下载语音程序和两份权重。
- [安装桌面客户端](README.md#client)：下载 `.exe`，选择安装位置。
- [每天启动](README.md#daily-start)：依次启动服务和客户端。
- [旧版升级](README.md#upgrade)：在原目录更新，保留配置和记忆。
- [常见问题](README.md#faq)：检查画面、声音、连接和记忆问题。

本项目基于 [Open-LLM-VTuber](https://github.com/Open-LLM-VTuber/Open-LLM-VTuber)。凛祢的安装和升级请以上面的项目指南为准。
