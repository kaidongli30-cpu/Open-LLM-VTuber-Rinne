# 私人凛祢 QQ 桥接插件

这个插件不使用 AstrBot 自带的大模型或人格。AstrBot 只负责接收 NapCat 发来的 QQ
个人号私聊，再把完整输入交给现有的 Open-LLM-VTuber-Rinne 后端。

当前行为：

- 群消息全部静默拦截。
- 只有配置中的一个主 QQ 号能与小号私聊。
- 普通消息只缓存，不回复。
- 单独发送 `over` 后才把此前所有文字按顺序提交。
- 单独发送 `/end` 会封存当前 QQ 聊天 JSON；它不会交给大模型，也不会让凛祢下线。
- 如果还有未 `over` 的缓存，`/end` 会要求先 `over` 或 `/cancel`，不会静默丢失输入。
- QQ 语音会在本机转换为 WAV，经凛祢后端 ASR 识别后作为一条输入缓存；仍要
  单独发送文字 `over`，语音中说出“over”不会触发回复。
- 图片、TXT、MD、PDF、DOCX 会先安全保存到用户配置的本机 inbox；仍要等 `over`。
- 图片会作为本轮视觉输入，文件只通过凛祢现有的只读资料库读取。
- 单个文件上限 50MB；不会执行收到的文件。
- 单条语音最长 5 分钟、最大 20MB。
- `/cancel` 清空尚未提交的内容。
- `/status` 只显示缓存条数，不显示内容。
- 后端输出按原生分句逐条发回 QQ。
- 在插件配置中填写独立的绝对 `data_root` 路径，缓存会原子保存到该目录；留空时插件不会接收私聊。
- 后端失败时不清空缓存。
- 标准聊天 JSON 由凛祢后端写入其 `chat_history/rinne_01`；插件缓存不是第二份长期记忆。

桥接令牌只从环境变量 `RINNE_PRIVATE_BRIDGE_TOKEN` 读取，不写入插件配置文件。
