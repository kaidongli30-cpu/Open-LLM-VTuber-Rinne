# 凛祢 QQ 桥接插件

这个插件把 QQ 私聊交给你正在运行的凛祢后端处理，再把回复发回 QQ。

AstrBot 只负责转交消息，不使用它自己的大模型或角色设定。完整安装步骤见 [QQ 通道说明](../../public_docs/QQ_SETUP.md)。

## 怎样聊天

1. 用配置中允许的主 QQ 号，给机器人小号发消息。
2. 可以连续发送几条，它们会先暂存。
3. 单独发送一条文字 `over`，凛祢才会一起读取并回复。

只接收指定账号的私聊，不处理群消息。后端回复会分句发回 QQ。

## 常用命令

| 单独发送 | 作用 |
| --- | --- |
| `over` | 提交目前暂存的消息，等待回复 |
| `/cancel` | 清空还没提交的内容 |
| `/status` | 查看暂存条数，不显示具体内容 |
| `/end` | 保存并结束当前 QQ 聊天记录，不会让凛祢下线 |

还有未提交的消息时，`/end` 会要求你先发 `over` 或 `/cancel`，不会直接丢掉消息。

后端处理失败时，暂存内容会保留。

## 语音、图片和文件

语音会先在本机转成 WAV，再由凛祢后端识别。识别结果也会先暂存，需要**另外发送文字 `over`** 才提交；在语音里说“over”不算。

图片、TXT、MD、PDF、DOCX 会保存到配置的本机 inbox，等待 `over`。

图片作为本轮视觉输入；文档通过凛祢的只读资料库读取，不会执行收到的文件。

大小限制：

- 单个文件：最多 50 MB。
- 单条语音：最多 5 分钟、20 MB。

## 数据和连接设置

在插件配置中，把 `data_root` 填成专门存放插件缓存的完整路径。留空时，插件不会接收私聊。

正式聊天记录仍由后端写入 `chat_history/rinne_01`。插件缓存只是暂存消息，不是另一份长期记忆。

连接后端的令牌从环境变量 `RINNE_PRIVATE_BRIDGE_TOKEN` 读取。它不是模型 API 密钥，设置步骤见 [QQ 通道说明](../../public_docs/QQ_SETUP.md)。
